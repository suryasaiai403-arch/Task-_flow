# Task Flow

Task Flow is a simple and responsive task management application built using **React and Vite**.

### Features

* Add, edit, and delete tasks
* Mark tasks as completed
* Filter tasks by All, Active, and Completed
* Set task priority and due date
* Form validation
* Tasks saved using local storage
* Responsive design

### Technologies

* React
* Vite
* JavaScript
* CSS
* Local Storage

### Run the Project

```bash
npm install
npm run dev
```

Task Flow helps users organize and manage their daily tasks efficiently.
